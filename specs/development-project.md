# Requisitos do projeto Ampara

## Contexto

O Ampara é o projeto de conclusão do programa Geração Tech do Ceará (Turma Aldeota): uma plataforma de telemetria e manutenção preditiva para veículos legados, começando pelo Chevrolet Classic e adaptador ELM327.

O estudante tem formação em Ciência de Dados e quer desenvolver competências de engenharia de software, qualidade, DevOps, cloud e infraestrutura como código. A implementação deve ser incremental e preservar sua autonomia de aprendizagem.

## Requisitos do programa

1. Aplicação com arquitetura clara e boas práticas de engenharia.
2. Módulos Terraform próprios e reutilizáveis.
3. CI/CD com Jenkins, além de fluxo de processamento de dados.
4. Testes automatizados unitários, de integração e de componentes.
5. Segurança considerada durante todo o ciclo de desenvolvimento.

## Diretrizes de aprendizagem

- Construir uma fatia pequena por vez e confirmar entendimento antes de seguir para a próxima etapa.
- Definir comportamento e critérios de aceite antes da implementação; os testes existentes são a especificação e não devem ser alterados para mascarar falhas do código.
- Explicar os princípios de engenharia aplicados e incentivar decisões próprias do estudante.
